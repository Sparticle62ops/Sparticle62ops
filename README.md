# sparticle

Independent ML research, self-taught. Everything open source.

## Current work

- **[PSSA](https://github.com/Sparticle62ops/pssa)** — a plastic state-space architecture: a language model that reads tokens through a recurrent state-space layer instead of attention. Trained from scratch in Rust, runs on CPU, CUDA and WebGPU.
  [site](https://sparticle62ops.github.io/pssa/) · [model card](https://huggingface.co/sparticle62/pssa) · [blog](https://sparticle62ops.github.io/pssa/blog.html)
- **Universal checkpoint converter** — turn any Hugging Face LLM checkpoint into a PSSA v6 checkpoint (`pssa convert`), shipping in the PSSA CLI.
- Distillation from a dense Qwen3 teacher, and a much bigger PSSA run in progress.
